Os grafos aleatórios sintéticos foram gerados programaticamente segundo o modelo Erdős–Rényi $G(n, p)$, utilizando a biblioteca NetworkX~\cite{networkx}. A geração foi controlada por uma semente fixa (\texttt{SEED = 42}) para garantir reprodutibilidade. Foram produzidos grafos distribuídos igualmente entre quatro valores de probabilidade de aresta: $p \in \{0{,}2;\, 0{,}4;\, 0{,}6;\, 0{,}8\}$, com 25 instâncias por nível de densidade. O número de vértices $n$ de cada grafo foi amostrado uniformemente no intervalo $[100, 1000]$, cobrindo instâncias de pequeno a médio porte. Cada grafo foi exportado no formato Matrix Market utilizando a biblioteca SciPy~\cite{scipy}, com o nome do arquivo composto pela combinação dos parâmetros $n$ e $p$ — por exemplo, \texttt{erdos\_n350\_p0.4.mtx}. Como o valor de $n$ é amostrado aleatoriamente, duas instâncias geradas para a mesma densidade podem eventualmente coincidir no mesmo $n$, resultando no reaproveitamento do arquivo correspondente. Com a semente adotada, esse fenômeno ocorreu uma vez para $p = 0{,}2$, de modo que a base final de grafos aleatórios totalizou 99 instâncias.
